# 草药谱 · MATERIA MEDICA

一个纯静态的本草索引站点，为原创角色写手、画手与考据党准备。
核心不是“背药名”，而是按角色的症状与功效反查：Ta病了，该拉哪一格抽屉？

**创作参考，非处方。本站不构成医疗建议，不要据此用药。**

## 本地预览

最简单：直接双击 `index.html`。数据通过 `<script>` 挂载，不使用 `fetch`，所以 `file://` 可以正常打开。

也可以起一个静态服务器：

```bash
cd 草药谱
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

## 部署到 GitHub Pages

1. 把 `index.html`、`styles.css`、`app.js`、`data/herbs.js` 推到仓库。
2. 在仓库 Settings → Pages 中选择分支与根目录。
3. 无需构建、无需 Node.js 或任何外部依赖。

## 已实现

- 120 味药材数据，15 类功效/症状反查：补气、补血、清热、解毒、活血、止血、安神、解表、化痰、止咳、消食、利水、温里、收涩、催情（叙事母题）。
- 搜索：中文名、英文名、学名、拼音、别名；`/` 聚焦搜索，`Esc` 关闭。
- 筛选：四气、五味、归经、功效、药用部位、禁忌标签；支持多选、已选条件移除与全部重置。
- 每页 15 条分页；移动端 390px 无横向滚动。
- 药对：48 组固定药对 + 详情页内可点击跳转到另一味。
- 详情抽屉：性味归经、禁忌与毒性、药对、产地采收炮制、形态、气味、文化、创作提示、误用、冷知识、校勘。
- 随机一味；`#id` 深链接（如 `#renshen`）；浏览器前进/后退同步。
- A5「药方签」打印，含「创作参考，非处方」与免责声明；120 条均已验证为单页 A5。
- 药材 SVG 为线描示意，不依赖照片与外部资源。

## 数据与安全边界

- 不写剂量、不写方剂配比、不写可服用的炮制步骤，也不提供自采自用方法。
- 孕妇禁忌与十八反/十九畏只做提示，不展开具体用法。
- 毒性药材（半夏、何首乌、附子、苦杏仁、桃仁、艾叶、细辛）在卡片、详情与打印卡上均显著标注毒性；细辛另标肾毒性风险，艾叶标为“小毒 / 谨慎使用”。
- 不确定的性味、归经、毒性、保护级别等字段显式写「资料待核」，不编造。

## 明确待核 / 可能引起争议的点

- **保护级别**：野生人参标注为国家一级重点保护野生植物；川贝母、石斛、半夏、黄连、何首乌、野生乌头属等的具体保护级别与物种范围仍有待按最新名录核对。站点使用「资料待核」而不是给确定结论。
- **孕妇用药**：多味药的孕期风险分级均未完成系统核对，标为「资料待核」，仅提示慎用/禁用；新增的苦杏仁、桃仁、红花、益母草、艾叶等仍需按个体与配伍复核。
- **新增毒性药材**：苦杏仁、桃仁含苦杏仁苷，艾叶与蛇床子标为有小毒，细辛含马兜铃酸类成分并有肾毒性风险，仙茅标为有毒；相关风险边界、炮制与剂量均未展开，不可据此自行使用。
- **补阳类与「催情」**：巴戟天、肉苁蓉、锁阳、补骨脂、菟丝子、韭菜子、蛇床子、仙茅、覆盆子、鹿茸的「催情」仅作叙事母题；传统补阳、固精、益精血的表述不能等同为催情功效。
- **新增基原/商品名**：怀牛膝与川牛膝、红花与藏红花、山茱萸与吴茱萸、紫苏叶与紫苏梗、板蓝根与大青叶、苦杏仁与甜杏仁、桃仁与苦杏仁，均存在容易混用的名称或部位。
- **分类与检索标签**：枸杞子传统上归补阴药，本站为反查方便挂「补血」检索标签；淫羊藿传统功用为补肾阳，本站归入「温里」检索标签，并以「催情」作为明确的叙事母题而非功效。白芍的「收涩」为次级检索标签。
- **十八反/十九畏**：桂枝与赤石脂的对应关系标为资料待核；其余相关条目只提示，不展开。
- **基原与商品名**：石斛（含铁皮石斛）、川贝母（松贝/青贝/炉贝）、五味子（南/北）、熟地黄与何首乌的植物分类与商品规格仍可进一步考据。
- **新增条目的分类**：党参、太子参、大枣、阿胶、栀子、知母、石膏、淡竹叶、蒲公英、白头翁、马齿苋、防风、白芷、细辛、辛夷、紫菀、款冬花、枇杷叶、瓜蒌、竹茹、石菖蒲、柏子仁、泽泻、薏苡仁、乌梅、大黄、茵陈、金钱草、猪苓、莲子、桑椹、合欢皮、夜交藤、生姜、芡实、芦根、天花粉、夏枯草、决明子、紫花地丁、败酱草、射干、延胡索、郁金、鸡血藤、仙鹤草、地榆、蒲黄、莱菔子、鸡内金的性味归经与安全分级，均以通行叙述为底，部分字段标为资料待核。
- **采收年限与产地**：具体栽培年限、采收物候、道地产区差异多为概括性描述，部分标为资料待核。
- **何首乌**：有肝损伤风险，生品与制品用途不同；站点按高风险管理，不提供任何可操作用法。

## 非生物与人体材料

本谱现在明确收录非植物材料：石膏、熟石灰、龙骨、磁石、代赭石（矿物/化石）；阿胶、鸡内金、鹿茸、牡蛎、珍珠母、海螵蛸、蝉蜕、地龙（动物药）；紫河车（人体材料）。

- **紫河车**：涉及人体来源、知情同意、感染筛查、伦理与法规；本谱只作历史文化与创作参考，不提供获取或使用方法。
- **熟石灰**：氢氧化钙，强碱、强腐蚀性；历史用途不等于安全，不提供外用或内服方法。
- 矿物与化石材料涉及资源、来源与法规，页面均标「资料待核」。

## 关于「催情」标签

本站把「催情」作为**小说叙事母题**，不是经证实的临床功效。当前共 11 味带此标签：淫羊藿、巴戟天、肉苁蓉、锁阳、补骨脂、菟丝子、韭菜子、蛇床子、仙茅、覆盆子、鹿茸。它们传统上多被归入补阳、固精或温肾类，但「补肾阳」「益精」不等于催情，也不提供任何用法、剂量或配方。

其中蛇床子标为小毒、仙茅标为有毒，鹿茸为动物药且涉及野生保护与养殖来源问题；页面均已显著提示，切勿据此自行使用。
